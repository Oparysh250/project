# Анализ чатов Telegram для построения FAQ

## Структура проекта

| Файл | Назначение |
|------|------------|
| `convector_to_txt` | Конвертер HTML-экспорта Telegram в TXT |
| `TF_IDF` | Анализ важности слов (для подбора категорий) |
| `major_program` | Основная программа: фильтрация, лемматизация, категоризация, дедупликация, сборка `faq.json` |

## Подготовка папок в Colab

Перед запуском программы создайте следующие папки в корневой директории Colab (`/content/`):

| Папка | Назначение |
|-------|------------|
| `/content/html_data_PD/` | HTML-файлы чата «Подслушано МИРЭА» |
| `/content/html_data_IIT/` | HTML-файлы чата «Поступление в ИИТ» |
| `/content/html_data_EX/` | HTML-файлы чата «Экзамены МИРЭА» |
| `/content/txt_data/` | Сюда сохранятся обработанные TXT-файлы (создаётся автоматически) |
